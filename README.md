# 卜易 · buyi

> 心存敬畏，卜以决疑，不疑何卜。

**在线看**：<https://chengyi-mountain.github.io/buyi/>　|　**本地看**：下载后双击 `index.html`

一个能双击打开、也能挂 GitHub Pages 的《周易》六十四卦参证单页站。一屏一卦：卦画六爻自绘，卦辞爻辞随卦而变，配一张人间道图解，另附人间道、阳宅学、案例三栏参证。

## 五个视图

| 视图 | 入口 | 内容 |
| --- | --- | --- |
| 首页 | 默认 | 当前卦象（默认第 1 卦乾为天）＋人间道图解＋上下两排六按钮 |
| 全卦 | 「全卦」 | 1—64 矩阵（桌面 8 列 / 手机 4 列），点任一卦回首页 |
| 解卦 | 「解卦」 | 弹窗输入所问（可空）→ 结论、要点、卦辞、六爻、意解 |
| 图解 | 「图解」 | 卦象＋图解整页＋图意＋卦辞，可点开原尺寸 |
| 全解 | 「全解」 | 左卦象与图，右三栏：人间道 / 阳宅学 / 案例 |

**按钮**：上一卦、下一卦按 1→64 循环；「每日一卦」三秒抽动后定卦（不点不改卦）；键盘 ← → 亦可换卦。

**地址可分享**：`#/home/3`、`#/tu/3`、`#/full/3`、`#/all/3` 直达某一卦；换卦时地址自动同步成当前卦号（`replaceState` 更新，不产生历史记录）。

**阅读层次**：解卦先给一句结论与两三条要点，卦辞、六爻、就所问与完整意解收在「展开卦辞、六爻与意解」里；全解三栏在手机上默认收起、点标题展开，桌面自动全开。

**素材**：`assets/renjiandao/001.jpg`～`064.jpg` 为竖版整页图解（1192×1685）。页面显示不带水印，只有点「下载此图」时由浏览器现叠一层极淡出处标再存盘。

**技术**：单个 `index.html`，CSS/JS 内联，数据固化进 `const YI`，不依赖框架与构建工具；本地双击即可，不用起服务。

## 目录

```
index.html              单文件页面（数据已内联，双击即可打开）
assets/renjiandao/      人间道图解，竖版整页，001.jpg ~ 064.jpg（1192×1685）
data/64gua.json         六十四卦卦名、卦辞、爻辞
data/notes_01..09.json  按卦号索引的三栏意解（r 人间道 / z 阳宅 / c 案例）
tools/                  抓取、注入、拆页、清单等脚本（用法见 MAINTENANCE.md）
```

## 改内容

1. **换三栏文本**：编辑 `data/notes_*.json` 里对应卦号的 `r` / `z` / `c`，再运行 `python tools/build.py` 重新注入 `index.html`。
2. **补图 / 换图**：把竖版整页图按 `001.jpg`（乾）到 `064.jpg`（未济）放进 `assets/renjiandao/`，页面自动引用；缺图显示「图位待置」。
3. **改页面样式与逻辑**：直接改 `index.html`（视图、CSS、`render` 系列函数都在这一个文件里）。

三栏默认内容是依卦辞爻辞推演的意解，**不是倪师原文**，页面已注明。

## 图片来源与下载标记

- 图解为《天纪·人间道》讲义扫描页，出处为使用者自备的 PDF；版权归原作者倪海厦与原出版方，本仓库不主张任何权利。
- **页面显示不带任何水印**；只有「下载此图」时，浏览器把图重绘到 canvas 后叠一层极淡对角出处标与一行来源说明，再另存为 `buyi-NNN.jpg`。仓库里只存一份原图。
- 本地以 `file://` 打开时浏览器取不到图（跨域限制），按钮会退化为直接打开原图，存下的文件不带标记——已知限制。
