# 卜易 · buyi

> 心存敬畏，卜以决疑，不疑何卜。

**在线看**：<https://chengyi-mountain.github.io/buyi/>　|　**本地看**：下载仓库，双击 `index.html`

一个能双击打开、也能挂 GitHub Pages 的《周易》六十四卦参证小站。一屏一卦：卦画六爻自绘，卦辞爻辞随卦而变，配一张人间道图解，另附人间道、阳宅学、案例三栏参证。

**一屏一卦**：卦象按六横线重绘（上爻在最上），旁边是卦名、上卦下卦与序位，随卦切换。

**五个视图**

- **首页**：卦象 + 卦名 + 人间道图解（整页），默认第 1 卦乾为天，六枚按钮分两排。
- **全卦**：1–64 矩阵（桌面 8 列 / 手机 4 列），点任一卦回首页并定位。
- **解卦**：弹窗输入所问（可留空），按当前卦给卦辞、六爻与意解；留空则只解经文。
- **图解**：卦象 + 图解整页 + 图意 + 卦辞，可点开原尺寸，底部有使用说明与风险提示。
- **全解**：左侧卦象与图，右侧三栏——人间道 / 阳宅学 / 案例。

**三种玩法**：上一卦、下一卦按 1→64 循环；「每日一卦」三秒抽动后定卦，不点则保持当前卦；键盘 ← → 换卦。

**素材**：`assets/renjiandao/001.jpg`～`064.jpg` 为竖版整页图解（1192×1685），页面显示不带水印，点「下载此图」时由浏览器现叠一层极淡出处标再存盘。

**数据**：卦爻经文抓自公有领域底本《周易》，落成 `data/64gua.json`；三栏文字目前是依卦辞爻辞推演的意解，不是倪师原文，页面与本文末尾均已注明。

**技术上说**：单个 `index.html`，CSS/JS 内联，数据固化进 `const YI`，不依赖任何框架与构建工具；本地双击即可，不需要起服务。

## 页面结构

| 视图 | 入口 | 内容 |
| --- | --- | --- |
| 首页 | 默认 | 当前卦象（默认第 1 卦乾为天）＋人间道图位＋上下两排六按钮 |
| 全卦 | 「全卦」 | 1—64 矩阵，卦画按六横线自绘，点任一卦回首页 |
| 解卦 | 「解卦」 | 弹窗输入所问（可空）→ 卦辞、六爻、意解，留空则只解经文 |
| 图解 | 「图解」 | 卦象＋人间道图＋图意＋卦辞，含「全解」入口 |
| 全解 | 「全解」 | 左卦象与图，右侧三栏：人间道 / 阳宅学 / 案例 |

按钮逻辑：上一卦、下一卦按 1→64 循环；「每日一卦」三秒抽动后定卦（不点不改卦）；键盘 ← → 亦可换卦。

**地址可分享**：`#/home/3`、`#/tu/3`、`#/full/3`、`#/all/3` 直达某一卦；换卦时地址会自动同步成当前卦号（用 `replaceState` 更新，不产生历史记录，不会污染浏览器后退）。`#/home` 这类不带卦号的地址也能用，默认落在第 1 卦。

## 目录

```
index.html              单文件页面（数据已内联，双击即可打开）
assets/renjiandao/      人间道图解，竖版整页，文件名 001.jpg ~ 064.jpg（1192×1685）
data/64gua.json         六十四卦卦名、卦辞、爻辞
data/notes_01..09.json  按卦号索引的三栏意解（r 人间道 / z 阳宅 / c 案例）
tools/fetch_text.py     抓取并解析《周易》原文 → data/64gua.json
tools/build.py          合并 64gua.json + notes*.json，注入 index.html
tools/split_book.py     把扫描版讲义 PDF 按页导出为 001.jpg ~ 064.jpg
tools/inspect_pdf.py    检查 PDF 页数、每页图片对象
```

## 改内容

1. **补图 / 换图**：把竖版整页图按 `001.jpg`（乾）到 `064.jpg`（未济）放进 `assets/renjiandao/`，页面自动引用；缺图时显示「图位待置」。
   - 有 PDF 时：`python tools/split_book.py <pdf> assets/renjiandao --mode full --dpi 150`
   - `--mode crop` 会尝试只裁画作区域，但各页画幅不一致时可能切坏，默认用 `full`（整页，含卦名与「卦圖象解」）。
2. **换三栏文本**：编辑 `data/notes_*.json` 里对应卦号的 `r` / `z` / `c`，然后运行 `python tools/build.py` 重新注入。
   - 若手上有一份《人间道》《阳宅》的整理文本，按卦号拆成同样字段填进去即可，页面结构不必改。
3. **重抓经文**：`python tools/fetch_text.py`。

三栏默认内容是依卦辞爻辞推演的意解，**不是倪师原文**，页面上已注明。

## 换电脑 / 继续修改

GitHub 上的仓库是唯一权威副本，本地那份只是工作副本。原电脑重装、换机器、文件误删，都不影响已经推上去的版本。

- **新电脑继续改**：装 GitHub Desktop → 菜单 `File` → `Clone repository` → 选 `chengyi-mountain/buyi` → 指定本地目录 → Clone。拿到的就是带完整提交历史的可编辑副本。
- **别用网页 Download ZIP**：只有文件、没有历史，改完再推容易和远端分叉。
- **改完推送**：GitHub Desktop 里 `Commit to main` → 右上 `Push origin`。
- **两边都改过**：先点 `Fetch origin`，再 `Pull`，处理完冲突再推。
- **不要在网页上直接上传同名文件改内容**：会和本地副本分叉，下次 Push 报 “Newer commits on remote”。
- **校验版本是否被改动**：`python tools/make_manifest.py` 重新生成 `NOTICE.sha256`，和已存的清单比对哈希即可。
